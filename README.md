H3 test task
=============================

Local development
-----------------

To install requirements: 
Create poetry environment and run `poetry install`\
OR\
Create virtualenv environment and run `pip install -r requirements.txt`


To run application `python src/__main__.py`. It will run development server on `http://0.0.0.0:8000`.
Docs on `http://0.0.0.0:8000/docs`


Linters:
--------

To run linters - `mypy -p src` and `ruff check`\
To run formatter - `ruff format`
